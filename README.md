# Monthly Student Performance Tracker 📈

A Python project that compares six students' monthly performance using line graphs.

## Features
- Tracks 6 students.
- Displays 12 months.
- Generates random data using NumPy.
- Creates and saves line charts.

## Requirements
```bash
pip install numpy matplotlib
```

## Run
```bash
python main.py
```

## Technologies
- Python
- NumPy
- Matplotlib

**Created for Python learning and data visualization.**
